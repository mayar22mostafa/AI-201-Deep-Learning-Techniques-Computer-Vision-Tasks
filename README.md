# AI-201-Deep-Learning-Techniques&Computer-Vision-Tasks
This repository contains all hands-on tasks completed as part of the **AI-201: Deep Learning Techniques & Computer Vision** course, offered in the 2nd semester of [Digilians Diploma] at NTI Egypt.

Each task applies core deep learning concepts and techniques covered throughout the course, ranging from building and training neural networks to implementing and evaluating models on real-world datasets.
